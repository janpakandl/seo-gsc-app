Zásady ochrany soukromí

Aplikace Betarena SEO GSC je soukromý nástroj Jana Pakandla. Přistupuje jen k údajům účtu, který ji sám autorizoval, a jen pro čtení (Google Search Console a Google Analytics 4).

  • Data se zpracovávají lokálně na počítači vlastníka a slouží k interním SEO analýzám.
  • Data se neprodávají, nesdílejí s třetími stranami a nepoužívají k reklamě.
  • Přístup lze kdykoli odebrat v nastavení účtu Google (Zabezpečení, Aplikace třetích stran).

Použití dat získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.
